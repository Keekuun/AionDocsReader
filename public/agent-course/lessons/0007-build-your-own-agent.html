动手写你自己的最小 Agent

前六课读的每一行 aionrs 源码，这一课都变成你自己指尖的代码。用 TypeScript 写一个 80 行的真 agent：循环 + 工具 + 护栏，能真的读你电脑上的文件。

完整代码（每一行你都认识）

新建文件 agent.ts。注释里标注了每段对应哪一课：

import fs from 'node:fs';

const API_KEY  = process.env.OPENAI_API_KEY;
const BASE_URL = process.env.OPENAI_BASE_URL ?? 'https://api.openai.com/v1';
const MODEL    = process.env.MODEL ?? 'gpt-4o-mini';
const MAX_TURNS = 8;                    // ← 第 6 课：护栏

// ── 工具（第 2 课：三张名片 + execute）──
const tools = [
  {
    name: 'read_file',
    description: '读取本地文件内容。file_path 必须是绝对路径。',
    schema: { type: 'object', required: ['file_path'],
              properties: { file_path: { type: 'string' } } },
    execute: ({ file_path }) =>
      fs.readFileSync(file_path, 'utf8').slice(0, 2000),  // ← 截断（第 3 课）
  },
  {
    name: 'list_dir',
    description: '列出目录下的文件。path 必须是绝对路径。',
    schema: { type: 'object', required: ['path'],
              properties: { path: { type: 'string' } } },
    execute: ({ path }) => fs.readdirSync(path).join('\n'),
  },
];

// ── 循环（第 1 课）──
async function run(question) {
  const messages = [{ role: 'user', content: question }];
  for (let turn = 0; turn < MAX_TURNS; turn++) {
    const res = await fetch(`${BASE_URL}/chat/completions`, {
      method: 'POST',
      headers: { Authorization: `Bearer ${API_KEY}` },
      body: JSON.stringify({
        model: MODEL, messages,
        tools: tools.map(t => ({           // ← 名片打包进请求（第 2 课）
          type: 'function',
          function: { name: t.name, description: t.description,
                      parameters: t.schema },
        })),
      }),
    });
    const msg = (await res.json()).choices[0].message;
    messages.push(msg);                   // assistant 入历史

    if (!msg.tool_calls?.length) {       // 最终答案 → 循环结束
      console.log('\n最终回答:\n' + msg.content);
      return;
    }
    for (const call of msg.tool_calls) {  // tool round
      const tool = tools.find(t => t.name === call.function.name);
      const args = JSON.parse(call.function.arguments);
      console.log(`→ 调用工具 ${call.function.name}(${JSON.stringify(args)})`);
      const result = tool ? tool.execute(args)
                          : `未知工具: ${call.function.name}`;
      messages.push({ role: 'tool', tool_call_id: call.id,
                      content: String(result) });  // 结果写回历史
    }
  }
  console.log('达到 max_turns，任务未收敛');  // 熔断
}

run(process.argv[2] ??
  '看看当前目录有什么文件，读一下 package.json 告诉我项目名字');
一个细节：OpenAI 兼容 API 用专门的 role: 'tool' 装工具结果；Anthropic 风格（aionrs）是伪装成 user 消息。写法不同，思想相同——工具结果作为新的输入回到历史。

动手任务（30 分钟，本课的完成即本课程的里程碑）

让你的 agent 真的跑起来

1. 把上面代码存为 agent.ts（放在任意目录）。

2. 设置环境变量（任何 OpenAI 兼容服务都行——OpenAI / DeepSeek / Kimi / 本地 Ollama）：

export OPENAI_API_KEY=你的key
export OPENAI_BASE_URL=https://api.deepseek.com/v1  # 以你用的服务为准
export MODEL=deepseek-chat

3. 跑起来：

~/.bun/bin/bun agent.ts

4. 观察输出：应该看到 → 调用工具 list_dir(...)，然后 → 调用工具 read_file(...)，最后是基于真实文件内容的最终回答。

✓ 完成标志：agent 通过真实工具调用读到了 package.json 并答对项目名。然后做三个进阶实验，每个都对应一课：① 把 MAX_TURNS 改成 1，问一个需要两步的问题，观察熔断；② 把 read_file 的 description 里「绝对路径」删掉，看模型会不会开始传相对路径（亲身体会 description 即 prompt）；③ 问一个目录里不存在的东西，看错误结果如何写回历史、模型如何自我纠正。

从玩具到生产：六课对照清单

你的 80 行 agent 和 aionrs 的差距，就是前六课的内容。逐项对照，这就是你以后迭代的路线图：

课机制你的玩具生产级（aionrs）
1循环✅ 已有+ 流式输出、turn 锚点、abort
2工具✅ 两个+ 注册表、并发安全、MCP 代理、延迟加载
3上下文⚠️ 只有截断+ 三级压缩、持久记忆、prompt 缓存
4权限❌ 没有+ 确认器、允许列表、plan 只读模式
5会话❌ 内存+ 每步落盘、文件锁、fork、格式迁移
6防护⚠️ 只有 max_turns+ 失败熔断、周期检测、模型自救警告
建议的迭代顺序：先加权限确认（一个 readline 询问就够），再加会话落盘（每步写 JSON 文件），最后上压缩。每加一个机制，你的 agent 就向生产级迈一步——而且你知道每个机制在 aionrs 里的参考实现在哪。
